## 背景
A-2 `SELECT (COUNT(*) AS ?count) WHERE { ?pe a jpost:PeptideEvidence }` が 1.6s かかっている。
これは 8.6M 行をスキャンして数えているが、`index.estimate(pattern)` が
p+o bound パターンで正確な件数を O(log N) バイナリサーチで返せる。

`src/index.rs` の `estimate_cardinality()`:
```rust
let (start, end) = self.range_for_pattern(&raw_pat);
if raw_pat[2].is_some() {
    ((end - start) as u64).saturating_add(1) / 2   // 3rd position bound → 50% heuristic
} else {
    (end - start) as u64   // ← p+o bound (POS) や s+p bound (SPO) → 正確な値
}
```

POS インデックスで `p=rdf:type, o=PeptideEvidence_id` の場合:
raw_pat = [p_id, o_id, None] → `raw_pat[2].is_none()` → `(end-start)` = 正確な件数 ✓

## 変更内容

### try_count_star_single_scan を追加

`try_count_star_cross_product` の近くに以下のメソッドを追加する:

```rust
/// Fast path for `SELECT (COUNT(*) AS ?alias) WHERE { single_triple_pattern }`.
///
/// When the plan is a single `Scan` (no joins, no filters) and the projection
/// is exactly one COUNT(*) alias, compute the count via `index.estimate()`
/// — an O(log N) binary-search range count — instead of materialising and
/// counting all matching rows.
///
/// `index.estimate()` → `estimate_cardinality()` returns the **exact** row
/// count when the tertiary (third) index column is unbound (i.e. at most two
/// positions are bound).  This covers the common patterns:
///   p + o  bound (POS)  →  `?s a SomeClass`        exact
///   s + p  bound (SPO)  →  `?x pred:functional ?y` exact (functional pred)
///   p only bound (POS)  →  `?s pred:any ?o`        exact
///
/// Only the 50% heuristic case (all three positions bound, direct lookup)
/// is approximate, but COUNT(*) of a fully-specified triple is 0 or 1 and
/// the heuristic doesn't matter there.
fn try_count_star_single_scan(
    &self,
    query: &SelectQuery,
    plan: &ExecutionPlan,
) -> Option<ResultSet> {
    // Guard: no GROUP BY, HAVING, DISTINCT.
    if !query.group_by.is_empty() || !query.having.is_empty() || query.distinct {
        return None;
    }

    // Projection must be exactly one COUNT(*) alias (no inner expr, not DISTINCT).
    let alias_name = if let Projection::Variables(items) = &query.projection {
        if items.len() != 1 { return None; }
        match &items[0] {
            SelectItem::Alias(
                Expression::Count { distinct: false, expr: None },
                name,
            ) => name.clone(),
            _ => return None,
        }
    } else {
        return None;
    };

    // Plan must be a single Scan (no joins, no filters, no path patterns).
    let pattern = match plan {
        ExecutionPlan::Scan { pattern, .. } => pattern,
        _ => return None,
    };

    // Count via index binary search — exact for ≤ 2 bound positions.
    let n = self.index.estimate(pattern);

    tracing::debug!(n, "single-scan COUNT(*): computed via index.estimate");

    let n_str = format!(
        "\"{}\"^^<http://www.w3.org/2001/XMLSchema#integer>",
        n
    );
    let n_id = self.dict.encode(&n_str);
    let mut result = ResultSet::empty(vec![alias_name]);
    result.rows.push(vec![Some(n_id)]);
    Some(result)
}
```

### execute_select での呼び出し追加

`try_count_star_cross_product` の呼び出し（`try_count_distinct_cross_product` の後）の
**直後** に追加する:

```rust
        if let Some(fast_result) = self.try_count_star_single_scan(query, &plan) {
            return fast_result;
        }
```

呼び出し順は以下になるはず:
```
try_count_distinct_cross_product  ← 既存
try_count_star_cross_product      ← 前回追加
try_count_star_single_scan        ← 今回追加  ← ここに挿入
```
