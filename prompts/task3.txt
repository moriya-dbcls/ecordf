# タスク3: store.rs を新 CompoundPath 型に対応

## 作業ディレクトリ
/home/moriya/tmp/ecordf

## 担当ファイル
- src/store.rs

## 背景
task7 が rdf_config.rs の CompoundPath 型を以下のように変更する:

```rust
// 変更前
pub type CompoundPath = Vec<String>;

// 変更後
pub type CompoundPath = Vec<(String, Cardinality)>;
```

store.rs の `build_path_cache_from_compounds` は現在
`compound_paths: &[Vec<String>]` と明示的に型注釈しているため、更新が必要。

## 変更内容

### 1. import に CompoundPath を追加

store.rs の先頭付近にある `use crate::rdf_config` の行を探し、
CompoundPath を import する。

現在:
```rust
use crate::rdf_config;
```

変更後:
```rust
use crate::rdf_config::{self, CompoundPath};
```

(もし既に別の形で import されていれば、そちらに `CompoundPath` を追加する)

### 2. build_path_cache_from_compounds のシグネチャ変更

現在 (663行付近):
```rust
    pub fn build_path_cache_from_compounds(
        &mut self,
        compound_paths: &[Vec<String>],
        budget_mb: u64,
    ) {
```

変更後:
```rust
    pub fn build_path_cache_from_compounds(
        &mut self,
        compound_paths: &[CompoundPath],
        budget_mb: u64,
    ) {
```

### 3. その他コンパイルエラーがあれば修正

上記の変更でコンパイルエラーが出る箇所があれば修正すること。
